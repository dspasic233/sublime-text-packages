Kubeapply Plugin for Sublime Text
=================================

Thank you for installing Kubeapply.

Requirements:
- kubectl installed and available on PATH (or set kubectl_path in settings)
- A valid kubeconfig with at least one context

Usage:
1. Open a Kubernetes YAML manifest
2. Cmd+Shift+P (Mac) / Ctrl+Shift+P (Win/Linux)
3. Run "Kubeapply: Apply Open File"
4. Pick a context from the quick panel
5. If a namespaced kind has no metadata.namespace, pick a namespace
6. Review the DIFF tab (syntax-highlighted) and confirmation prompts before apply

Safety defaults:
- Explicit --context on every kubectl call
- Server-side dry-run before apply
- kubectl diff shown before overwriting existing resources
- Extra confirmation for contexts matching *prod* patterns
- Never uses --force

Settings: Preferences → Package Settings → Kubeapply
